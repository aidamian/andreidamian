PurpleRay / SBOM Analyzer

Know what’s in
your software.

A small, native desktop application that turns local software artifacts into a software bill of materials. Inspect components, compare scans, and export CycloneDX.

Choose your download ↓ View source on GitHub ↗

Windows x64 · Linux x64 · macOS availability · Open source · Apache-2.0

From files to an inventory

A software inventory you can inspect.

01

Scan locally

Read package manifests, lock files, and native binaries. Scans run offline by default and never execute files in the selected folder.

02

Review what changed

Explore components and their evidence, compare completed scans, and review known issues through an optional OSV.dev check.

03

Export useful evidence

Produce a deterministic CycloneDX SBOM, export security findings, and inspect a BSI readiness report to see where inventory evidence is incomplete.

Online advisory checks are optional and require confirmation each time. They send only eligible, versioned Package URLs to OSV.dev. Readiness reporting helps review the evidence; it does not certify compliance.
